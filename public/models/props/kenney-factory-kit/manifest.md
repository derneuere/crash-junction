- IMPORTANT: these .glb files reference an EXTERNAL texture `Textures/colormap.png`
  (relative URI). Keep the Textures/ subfolder next to the .glb files.

Only the two dockside warning beacons were kept — the rest of the kit is indoor
factory machinery (conveyors, pipes) that does not fit an open harbor. Native
scale is already roughly metres. Origins at base (y=0).

| File | Native W x H x D | Description / suggested in-game footprint |
| --- | --- | --- |

| warning-traffic.glb | 0.40 x 1.55 x 0.40 | Striped pole with traffic beacon. Scale 1.0-1.3x. Mix with barriers at shortcut mouths. |
